# Solutions

For facilitators to check work against, and for students who get stuck and want to peek — either is fine. Try each exercise yourself first if you can, but there's no penalty for checking early if you're lost.

Every module folder here holds two kinds of file:

- **`solution.md`** (or the actual code, for Labs 3 and 5) — a worked example of a complete answer. For Labs 1, 2, 4, and 6, it's one valid way to do the exercise, not the only correct one.
- **`explanation.md`** — the *why* behind the solution: what the underlying mistake or gap usually looks like, why the fix works, and what the exercise is actually trying to teach. Read this even if you got the exercise right — it's where the transferable lesson lives.
