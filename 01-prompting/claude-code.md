# Lab 1 (Claude version) — Turn a vague request into a working brief

Same exercise as [TASK.md](TASK.md), phrased for Claude instead of ChatGPT. Use whichever you have: Claude Code (if you have API billing or a paid Pro/Max login) or the **free** chat at [claude.ai](https://claude.ai) — this exercise is plain conversation, not file editing, so the free web chat does it just as well as Claude Code.

## Vague request

> Create a campaign for our college event.

## Your task

Rewrite the request using five fields:

1. Context
2. Outcome
3. Inputs
4. Constraints
5. Quality bar

Use [prompt-template.md](prompt-template.md), then ask Claude for a first draft. Evaluate it with [response-scorecard.md](response-scorecard.md) and improve it twice: once for correctness and once for usefulness.

## Definition of done

- [ ] Audience and channel are explicit.
- [ ] Missing facts are marked as questions, not invented.
- [ ] Output format and length are stated.
- [ ] The response scores at least 8/10 on the scorecard.

Stuck, or want to check your work? See [../solutions/01-prompting/solution.md](../solutions/01-prompting/solution.md) for a worked example and [../solutions/01-prompting/explanation.md](../solutions/01-prompting/explanation.md) for why it's built that way.
