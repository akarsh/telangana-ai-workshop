# Response scorecard

Score each dimension 0, 1, or 2.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Correctness | Invents facts | Some unsupported detail | Uses only supplied facts |
| Audience fit | Generic | Partly tailored | Clearly designed for audience |
| Usefulness | Not actionable | Needs editing | Ready for next step |
| Format | Ignores request | Mostly follows | Fully follows |
| Transparency | Hides uncertainty | Vague caveats | Clearly marks assumptions |
