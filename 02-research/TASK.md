# Lab 2 — Build an evidence-backed recommendation

Use `source-pack.md`. Answer:

> Which workshop format should the organizing team choose, and why?

## Required output

1. A three-row evidence table: claim, supporting source, confidence.
2. A recommendation of no more than 120 words.
3. Two uncertainties that could change the recommendation.
4. A list of facts that must not be inferred.

## Verification

Every non-trivial claim must point to a source label from the source pack. If the source pack does not support a claim, write `not established`.
